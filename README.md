# BananaOS

BananaOS is a self-contained, single-file desktop simulation. It runs in a modern browser without a build step, backend, or external assets.

## Run it

Open `index.html` in a browser, or publish the repository with GitHub Pages:

1. In the repository settings, open **Pages**.
2. Select **Deploy from a branch**, choose the branch and `/ (root)`, and save.
3. Visit the Pages URL after deployment completes.

## What's inside

- A draggable desktop, app launcher, taskbar, live clock, and quick settings.
- Resizable, movable, minimizable, and maximizable app windows.
- BananaBrowse with interactive local Google-, YouTube-, and Wikipedia-inspired demos, plus direct HTTP/HTTPS browsing.
- Banana Mind chat and an AI-enabled simulated terminal.
- A simulated Retro DOS and Linux Lite virtual machine, local notes and files, settings, and an installable calculator.
- Optional synthesized interface sounds; settings and user-created notes are saved in this browser.

Direct websites can block embedded browsing. Use BananaBrowse's **Open in new tab** action when that happens. The app does not use public proxy services; the built-in demo sites work offline.
